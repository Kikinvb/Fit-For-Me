# Fit For Me

第 1–6 周新手 A/B 力量计划网页（每周 3 练，手机友好）。

## 本地打开

```bash
cd C:\Users\dsoth\Projects\Fit-For-Me
npx --yes serve -l 5173
```

手机同一 Wi‑Fi 访问：`http://你的电脑IP:5173`

## 使用

- 顶部切换本周是 **A/B/A** 还是 **B/A/B**
- 点星期查看当天内容；训练日含热身、4 个动作要点与起始试重
- 训练日可勾选完成动作
- 「进阶」：上手流程、双重渐进与试重表
- 「统计」：各动作累计完成次数
